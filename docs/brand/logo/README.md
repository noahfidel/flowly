# Flowly logo

![Flowly logo overview](overview.png)

The mark is a "status path": a start circle (Todo, handed to the agent) → a small path that turns twice (the card walks through Design → Development → Test by itself; Paseo originally means taking a walk) → a circle with a dot (in progress) → a circle with a check mark (finally signed off by you; Done is your decision). The stretch that goes up from the middle circle and then turns right hides the hook of an f.

The mark uses strokes only: a 64-unit canvas, 4-unit line width, round caps and joins; the check mark is one step thinner (3 units) to separate it from the circles. The wordmark is "Flowly", converted to paths from Inter Medium (SIL Open Font License 1.1), capitalized, with letter spacing tightened by 1%, so it needs no font file. It has details that echo the mark: the tops of the two l's and the tail of the y are cut at an angle (the path's rise to the upper right), and the o holds a dot (the in-progress circle). All SVGs are generated by `../export-logo.mjs`: the geometry of the mark is in the script, and the outlines of the wordmark are in `../wordmark.json`.

## Usage rules

- Clear space: leave at least the diameter of the check circle (1/4 of the mark height) on all sides.
- Minimum size: 32 px for the standard version, 16 px for the small version; the lockup height must not be below 20 px.
- Color: the logo uses a single color only, `#1E2120` on light backgrounds and `#F3F1EC` on dark ones; no brand colors (decided 2026-10-21, candidate comparison in `../logo-drafts/v7-colors/`). Accent colors in the plugin UI follow the Paseo theme.
- Do not retype the wordmark in another font, change its letter spacing or remove its details; to change the wordmark, regenerate it with the steps below.
- Do not fill the circles or the path with color, change the line width, stretch, rotate, add shadows or outline them.
- The plugin icon in the Paseo sidebar accepts only a Lucide icon name (currently `PanelsTopLeft`), so this mark is not used there.

## Regenerate

```sh
node docs/brand/export-logo.mjs
```

Needs Playwright and ImageMagick (`magick`). The wordmark outlines are already stored in `../wordmark.json` and normally need no regeneration; to change the text, weight or letter spacing:

```sh
python3 -m venv /tmp/flowly-fonttools  # Python 3.11–3.15 all work && /tmp/flowly-fonttools/bin/pip install fonttools uharfbuzz
/tmp/flowly-fonttools/bin/python docs/brand/outline-wordmark.py ~/Library/Fonts/Inter-Medium.ttf Flowly -20 --l-slant --o-dot --y-slant 60 > docs/brand/wordmark.json
```

When Playwright is not on the module path, use `PLAYWRIGHT=<playwright entry>`; when the bundled browser is missing, use `CHROMIUM=<path to chrome-headless-shell>`.

Drafts and the exploration process are in `../logo-drafts/`: `v1-filled` (colored), `v2-line` (line art), `v3-h-as-f` (an attempt to turn the H into a clear f shape, not adopted), `v4-h-refined` (four refinements of the original H; the final uses R1 "refined"; R2 "connected" is the alternative), `v5-wordmark` (seven ways to write the wordmark, W5 "Inter Medium · capitalized" chosen), `v6-wordmark-details` (ten combinations of details on W5, D8 "l slant + o center dot" chosen), `v8-y-slant` (the ending of the y tail: round tail, as-is and two slants, the final uses Y2 "slant 52°"), `v7-colors` (theme color candidates, the conclusion is to use a single color), `v9-y-angle` (comparison of 52° and 40° slants for the y tail, 52° chosen), `v10-check` (check mark thickness, K2 chosen: 3 units, enlarged 12%), `v11-small` (first round of the small version: a two-node staircase and a thin three-circle line, not adopted), `v12-two-ends` (small version with equal ends, T5 chosen: solid start, hollow end, S curve, visually equal size). Small drafts are rendered at real pixels with `node docs/brand/render-small.mjs <set>` to produce comparison images.
