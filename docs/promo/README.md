# Ultra Kanban — launch / promo material

In one sentence: **turn the agent sessions in Paseo into a board that moves by itself.** You only assign work, make the calls and accept the results; progress, reminders, summaries, follow-up ideas and data reviews are kept up by the board itself.

## Five headline features (screenshot → copy)

| # | Feature | Screenshot | Copy |
| --- | --- | --- | --- |
| 1 | Automatic status flow | `screenshots/01-board-auto-status.png` (dark: `…-dark.png`) | The agent starts, plans, codes, verifies and delivers, and the card moves between Design → Development → Test → In review by itself. A finished turn never marks a card Done; the right to accept is always yours. / Cards move across lanes as the agent plans, codes, verifies and delivers. A finished turn never marks a card Done — you do. |
| 2 | Human-input reminders | `screenshots/02-needs-you-drawer.png` | When the agent hits something you must decide (such as 410 or 404), it asks and stops; the card lights up **Needs you**, Attention at the top collects them, and Reply goes straight to that session. / The agent asks, stops, and the card lights up “Needs you”; Reply jumps straight to the session. |
| 3 | Task run summary | `screenshots/03-card-summary.png` | Written automatically at the end of every turn: a one-line state, the goal, completed points and next steps, with earlier versions kept. After Done you can still look back at how far it got. / Auto-written after every turn: state, target, recap, next — with version history. |
| 4 | Task follow-up ideas | `screenshots/04-ideas-inbox.png`, `04b-good-idea-two-paths.png` | Follow-up work the agent finds while working (making something configurable, Redis rate limiting, a bug found along the way) goes into the Ideas inbox. A good idea has two paths: continue in the original session, or create a new card / new session. / Follow-up work found along the way lands in an inbox; accept it into the same session or a new card. |
| 5 | Project insights | `screenshots/05-insights.png` (dark: `…-dark.png`, mock data, generated by `insights-mock.mjs`) | A one-year activity heatmap, a daily summary you can page through day by day with the time spent on each card, skills drafted from cards, and review rounds and tokens by model for the last 7 days. / A year of activity, a day summary you can page through, skill drafts and the last 7 days' review rounds and tokens by model. |

## Demo project

> After the screenshots were taken, the demo project (board records, Paseo project, Haiku sessions, temporary directory) was cleaned up; to retake them, rebuild it with the scripts below. The screenshot script hides the tabs of other projects and crops out the host sidebar.

- **Tinylink**: a dependency-free Node short-link service with a real git history of 6 commits.
- 6 cards: Done 1 / In review 3 (rate limiting, click statistics, custom aliases, all really implemented and committed by Haiku 5.5, tests passing) / Design 1 (expired-link bug, asking the user a question) / Todo 0 / Backlog 1.
- 3 ideas were proposed by the agent through `kanban_propose_idea` (covering both "continue in this card" and "create a new card").
- All sessions are `claude/claude-haiku-5-5`.

## Reproduce / retake

```
node docs/promo/setup.mjs                         # create the Tinylink repo, project and cards, and start 3 Haiku sessions
node docs/promo/setup.mjs --no-sessions           # create only the repo, project and cards, start no sessions (for single-pane live checks)
node docs/promo/start-session.mjs "Custom aliases" "<prompt>"   # add one more session
node docs/promo/shots.mjs board drawers ideas settings i18n  # screenshots (headless Chromium, 2× resolution, host sidebar cropped out)
node docs/promo/insights-mock.mjs && node docs/promo/insights-mock.mjs docs/promo/screenshots/05-insights-dark.png dark  # Insights with mock data (Tinylink's own data is too thin)
```

Screenshots crop only the plugin panel, without the personal workspaces in the host sidebar.
